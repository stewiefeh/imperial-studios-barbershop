# Imperial Studios Barbershop — sample website

A one-page site concept for Imperial Studios Barbershop, 761 Middle Country Rd, Suite 8,
Selden, NY 11784. Built as a from-scratch sample: no template, no framework.

**Live:** GitHub Pages serves the `main` branch root.

## What's inside
- `index.html` — the whole page
- `styles.css` — tokens, layout, motion (CSS scroll-driven layer + load sequence)
- `script.js` — open/closed status, today's hours row, review count-up
- `assets/` — photography from the shop's Google listing, optimized

## Identity
Lacquer black + imperial gold + the shop's Kobalt-lime workstations as the electric accent.
Cinzel (Roman inscriptional caps) for display, Archivo for body. All motion is
progressive enhancement: unsupported browsers and reduced-motion users get the
complete static page.
